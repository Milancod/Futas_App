# Maratonnapló

iPhone-ra optimalizált futáskövető webapp. Rögzítsd a dátumot, távot, időt és megjegyzést; kövesd a heti kilométereket, tempót és futásszámot. Támogat CSV-exportot és JSON biztonsági mentést.

## iPhone telepítése
1. GitHubon nyisd meg Settings → Pages.
2. A Build and deployment résznél válaszd a Deploy from a branch lehetőséget.
3. Branch: main; Folder: /(root), majd Save.
4. Várd meg a deploy befejezését, majd nyisd meg a GitHub Pages által jelzett HTTPS-címet Safariban.
5. Megosztás → Hozzáadás a Főképernyőhöz.

A napló a böngésző helyi tárhelyén marad; eszközcsere vagy böngészőadat-törlés előtt készíts JSON biztonsági mentést. A visszaszámláló 2027. október 1-jét használja alapértelmezésként.
